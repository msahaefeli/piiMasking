# システムアーキテクチャ

## 概要

Azure Durable Functions を使用した非同期PII（個人情報）マスキングシステム。Microsoft Teams会議のトランスクリプト（WebVTT形式）から、Azure OpenAI（GPT-4o）を利用して個人情報と医療情報を自動的にマスキングします。

## 主要コンポーネント

### 1. HTTP Trigger (PiiMasking_HttpStart)

**責務**:
- クライアントからのリクエスト受付
- リクエストボディのバリデーション
- Durable Orchestration の開始
- ステータス確認URLの返却

### 2. Orchestrator (PiiMasking_Orchestrator)

**責務**:
- ワークフロー全体の制御
- Activity の呼び出し
- カスタムステータスの設定
- リプレイセーフな実装

### 3. Activity (PiiMasking_RunAnalyze)

**責務**:
- 実際のマスキング処理実行
- Azure OpenAI API呼び出し
- エラーハンドリング
- リトライロジック
- Azure Storageアップロード

## チャンク分割戦略

### 分割条件
- VTT サイズ > 10,000文字の場合、チャンク分割

### 分割アルゴリズム
1. VTTをキュー単位で分割
2. キューを50個ずつチャンクにグループ化
3. 各チャンクを個別にマスキング
4. ヘッダー + マスキング済みチャンクを結合

### メリット
- メモリ効率化
- タイムアウト回避
- Content Filterエラー対策
- 並列処理可能（将来）

## エラーハンドリング

### リトライ戦略
- 最大リトライ回数: 3回
- バックオフ: 指数バックオフ（1s → 2s → 4s）
- Jitter: ランダム遅延追加

### Content Filter エラー
- エラー検出時: ログ警告
- そのチャンクは元のまま保持
- 処理継続

## セキュリティ

### 認証
- Function Key認証
- Azure OpenAI API Key

### データ保護
- HTTPS通信のみ
- Azure Storage暗号化
- 環境変数でシークレット管理

## パフォーマンス

### 処理時間
| VTTサイズ | チャンク数 | 処理時間 |
|----------|----------|---------|
| 5,000文字 | 1 | ~10秒 |
| 10,000文字 | 1 | ~15秒 |
| 14,000文字 | 3 | ~30秒 |
| 50,000文字 | 10 | ~90秒 |

### スケーラビリティ
- 最大インスタンス数: 200（従量課金プラン）
- 制限要因: Azure OpenAI TPM/RPM
